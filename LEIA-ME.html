🚛 Conferência Geral

Guia de Configuração e Deploy — Siga os passos abaixo para colocar o sistema no ar.

1

Criar projeto no Firebase

Acesse console.firebase.google.com e clique em "Criar projeto".

  • Dê o nome: conferencia-geral
  • Google Analytics: opcional (pode desativar)
  • Aguarde a criação e clique em "Continuar"
2

Ativar Autenticação (Email/Senha)

No menu lateral do Firebase, vá em Authentication → Sign-in method.

  • Clique em "Email/senha"
  • Ative a primeira opção "E-mail/senha"
  • Salve
3

Criar banco Firestore

No menu lateral, vá em Firestore Database → Criar banco de dados.

  • Selecione "Iniciar no modo de produção"
  • Localização: southamerica-east1 (São Paulo)
  • Clique em "Ativar"

Depois de criado, configure as Regras de Segurança (aba "Regras"):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
⚠️ Importante: Esta regra permite acesso somente a usuários logados. É suficiente para começar com segurança.
4

Ativar Firebase Storage (para fotos)

No menu lateral, vá em Storage → Primeiros passos.

  • Selecione "Iniciar no modo de produção"
  • Localização: southamerica-east1

Configure as regras do Storage (aba "Regras"):

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if request.auth != null;
    }
  }
}
5

Obter as credenciais do projeto Mais importante

No console do Firebase, clique no ícone ⚙️ Configurações do projeto (roda dentada no menu lateral).

  • Role a página até "Seus aplicativos"
  • Clique em "Web" (</>)
  • Registre o app com o nome conferencia-geral
  • Copie o bloco firebaseConfig que aparece

Ele terá este formato:

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "conferencia-geral.firebaseapp.com",
  projectId: "conferencia-geral",
  storageBucket: "conferencia-geral.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};
6

Colar as credenciais no arquivo firebase-config.js

Abra o arquivo firebase-config.js nesta pasta e substitua os valores da variável FIREBASE_CONFIG pelos dados que você copiou no passo anterior.

O início do arquivo ficará assim:

const FIREBASE_CONFIG = {
  apiKey:            "AIzaSy...",          // ← cole aqui
  authDomain:        "conferencia-geral.firebaseapp.com",
  projectId:         "conferencia-geral",
  storageBucket:     "conferencia-geral.appspot.com",
  messagingSenderId: "123456789",
  appId:             "1:123456789:web:abc123"
};
7

Fazer o deploy com Firebase Hosting Gratuito

O Firebase Hosting serve os arquivos na internet com HTTPS. Você precisará do Node.js instalado.

  • Instale o Firebase CLI: abra o Prompt de Comando e execute:
    npm install -g firebase-tools
  • Na pasta do projeto, execute: firebase login
  • Em seguida: firebase init hosting
  • Quando perguntar o diretório público, pressione Enter (usa . para a pasta atual)
  • Quando perguntar "Configure as a SPA?", digite N
  • Execute: firebase deploy
💡 Alternativa mais simples: Suba os arquivos diretamente no console do Firebase em Hosting → Começar usando o arrastar & soltar de arquivos.
8

Primeiro acesso — criar conta admin

Após o deploy, acesse a URL do seu projeto (ex: https://conferencia-geral.web.app).

  • Clique em "Primeiro acesso? Criar conta de administrador"
  • Preencha seu nome, e-mail e senha
  • Clique em Criar conta admin
  • Você será redirecionado automaticamente para o painel

📱

Compartilhar com conferentes

No painel admin, crie os conferentes com e-mail e senha. Depois envie a eles:

  • O link do sistema (ex: https://conferencia-geral.web.app)
  • O e-mail e a senha criados para eles
  • No celular, eles verão automaticamente a interface mobile
  • Para adicionar à tela inicial do celular: abrir no Chrome → menu → "Adicionar à tela inicial"

✅ Sistema pronto!

Após configurar as credenciais e fazer o deploy, o sistema estará funcionando completamente:

  • Admin acessa o painel web
  • Conferentes acessam pelo celular
  • Dados sincronizam em tempo real
  • Planilha Google Sheets é lida automaticamente
