📋 Alterar Planilha

Cole o link ou ID da nova planilha. A troca entra em vigor imediatamente para todos os conferentes.

Como encontrar o ID?

Abra a planilha no Google Sheets. O link terá este formato:
docs.google.com/spreadsheets/d/ID_AQUI/edit

Cole o link completo ou só o ID em negrito. A planilha precisa estar como pública para visualização.

⚠ Se o ID não estiver salvando: verifique as Regras do Firestore no Firebase Console e certifique-se de que usuários autenticados têm permissão de leitura e escrita. A coleção usada é config.

🗑️ Zerar Base Anterior a 30/06/2026

Apaga permanentemente todas as Operações (Entrada e Saída), Discrepâncias e o histórico de Movimentações de insumos com data/hora anterior a 30/06/2026 00:00. O saldo atual dos insumos não é alterado — apenas o histórico anterior é removido. Esta ação não pode ser desfeita.
